# NOVITA Beauty Salon — клікабельний прототип Telegram Mini App

Демонстраційний прототип онлайн-запису: каталог послуг, майстри, запис у 4 кроки, особистий кабінет з правилом «скасування не пізніше ніж за 24 години», лояльність, макет повідомлень бота, макет адмін-панелі.

- Назва, адреса, телефон, графік і каталог послуг узяті з технічного завдання салону. Майстри, відгуки, рейтинги, бонуси та частина цін (зони лазерної епіляції, перукарські послуги) — **демо-дані**.
- Реальних інтеграцій (CRM, платежі, бот) і авторизації адміністратора немає.
- Працює в звичайному мобільному браузері і як Telegram Mini App (один файл `index.html`, без збірки).
