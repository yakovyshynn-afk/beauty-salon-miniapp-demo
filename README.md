# Telegram Mini App для салону краси — клікабельний прототип

Демонстраційний прототип: каталог послуг, майстри, запис у 4 кроки, особистий кабінет з правилом «скасування не пізніше ніж за 24 години», лояльність, макет повідомлень бота.

- Усі дані — **демо-дані** (вигадані назви, ціни, майстри).
- Реальних інтеграцій (CRM, платежі, бот) немає.
- Працює в звичайному мобільному браузері і як Telegram Mini App (один файл `index.html`, без збірки).
